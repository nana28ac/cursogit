# MiniCurso - Desmistificando o Git e GitHub: Do Blob ao Push

## Passo a Passo da Dinâmica:

1. Instale o servidor local:
   \`npm install\`

2. Execute o projeto para visualizar a página web:
   \`npm start\`
   *(Uma aba vai se abrir no seu navegador!)*

3. Volte ao terminal e simule a compilação do projeto para produção:
   \`npm run build\`
